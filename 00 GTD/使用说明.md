# 使用说明

[[00 GTD/首页|返回首页]] · [[00 GTD/00 工作区/00 功能页面/收件箱|收件箱]] · [[00 GTD/00 工作区/00 功能页面/项目属性.base|项目属性]] · [[00 GTD/00 工作区/00 功能页面/项目总览|项目总览]]

日常操作集中在首页：**收集箱 → 项目进度 → 日历**。

## 每天怎么用

1. 点收集箱区的“快速收集”，先记下想法和待办。
2. 整理收集项时点“移入”，选择项目和父任务；也可以在项目中直接添加任务、拆解子任务。
3. 用“今”加入今天，用“排”安排多天；有期限时再填写任务的“截止”。
4. 在日历查看安排，在任务树或日历中勾选完成。需要调整名称或项目截止日期时，直接在首页修改。

## 修改任务与项目名称

项目进度中的名称平时显示为纯文字，**点击后才进入编辑**，没有常驻的“✓”“×”改名按钮。

- **Enter：**保存并退出编辑。
- **点到别处：**自动保存并收起输入框。
- **Esc：**取消本次修改，保留原名称。
- **点击另一个名称：**先保存、收起上一项，再编辑新的一项；同一时间只编辑一个名称。
- **清空名称后离开：**恢复原名称；删除任务请用任务行右侧的“×”。

任务改名只修改名称，保留父子层级、说明、完成记录、多日安排、截止日期和原有任务属性，日历中的名称会同步更新。日期继续使用“截止／今／排”设置。

项目改名会修改同一文件夹中的笔记文件名，并由 Obsidian 更新相关链接。项目内容、领域和截止日期保留，展开状态和显示顺序随项目保留。同一文件夹内不能重名，名称不能包含文件路径符号。

保存失败时会保留输入并显示原因。修正后可重试；需要重新选择任务时，先复制要保留的名称，再按 Esc 或点错误提示后的“取消”退出。

## 添加与拆解任务

点项目行“＋”添加顶层任务，点任务行“＋”添加子任务，可继续逐层拆解。已完成的任务需先恢复为未完成，才能继续添加子任务。

添加任务使用行内输入框：**Enter 添加后可继续输入**。点击框外会暂存草稿并收起，再点同一个“＋”可继续输入；按 Esc 或点输入框旁的“×”会关闭并清空未提交内容。已添加的任务保留。子任务输入框按层级缩进，与该层任务名称对齐。

在项目区域输入任务、修改名称或选择日期时，后台刷新会暂缓，保留输入法、草稿和光标。离开输入框后再合并更新，刷新保持原滚动位置。Enter 提交和 Esc 取消仍立即生效。

新建项目、新建领域和快速收集的表单支持连续提交，完成后点“关闭”。

任务层级使用 [Radix Colors 第 4 阶](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)中的八级循环底色：**浅金灰、浅蓝、浅琥珀、浅紫、浅梅粉、浅靛蓝、浅橙、浅紫灰**，超过八级后循环使用。文字统一保持深色；新任务输入框使用即将创建的层级底色，已完成任务文字仍灰化。采用“柔和行底”：Radix 原色以 32% 比例与米白底色混合，行间留白 2px，避免连续任务连成大色块。仅采用官方色值，不需要增加插件或安装 Radix。

父任务与子任务分别勾选：完成父任务不会批量完成子任务；子任务全部完成后，父任务仍可单独勾选。展开、折叠状态会保存。

项目进度按**已完成的末级任务数 ÷ 全部未取消的末级任务数**计算。带子任务的上层任务不重复计数；同一个任务安排多天也只计一次。项目没有任务时显示“—”。

## 已完成任务显示

项目进度顶部只有一个**眼睛按钮**，控制本页所有项目的已完成任务显示。

- **默认显示：**已完成任务保留在原来的父子层级和顺序中，以勾选和删除线标识。
- **点击眼睛隐藏：**收起已完成、且全部子任务也已完成的分支；再次点击恢复显示。选择会保存，本页的多个打开窗口会同步。
- **保留未完成内容：**已勾选的父任务下仍有未完成或取消的子任务时，父任务继续显示。未勾选的父任务也会保留，方便继续拆解或单独完成。
- **查看与恢复：**显示已完成任务后，取消勾选即可恢复未完成状态，仍在原来的位置。
- **记录和进度：**显示切换不移动、删除或修改笔记里的任务，项目进度继续包含全部任务。
- **未保存输入：**切换隐藏时，尚在编辑的任务名称或子任务草稿会保留一份；已完成父任务需先取消完成，才能继续添加子任务。

整项项目结束后，可使用项目状态菜单中的“完成”或“归档”。项目进度的眼睛与日历的眼睛分别控制各自区域。

## 整理收集箱

“快速收集”写入[[00 GTD/00 工作区/00 功能页面/收件箱|收件箱]]笔记。首页收集箱只显示其中的未完成事项；勾选后从首页列表移除，源笔记保留完成记录。

点“移入”选择项目。父任务选“无”时作为顶层任务，也可以选择一个未完成的父任务。移入会带上该项的全部子任务、缩进说明、多日安排和截止日期，并移除收件箱中的原项。

如果选择期间收件箱或目标父任务发生变化，会提示重新选择，尚未移走的收集项仍留在收件箱。

## 安排日期与截止日期

| 日期 | 在哪里修改 | 日历中的显示 |
| --- | --- | --- |
| 任务安排日期 | 任务行“今”“排” | 可安排多天，各天分别显示 |
| 任务截止日期 | 任务行“截止” | 截止当天显示红底卡片 |
| 项目截止日期 | 项目行“截止日期”或项目属性 | 作为项目期限显示，不自动生成任务卡片 |

**安排日期**表示准备在哪些天推进任务，**截止日期**表示最晚完成期限，两者分别维护。项目截止日期不会自动修改各任务的截止日期，父任务和子任务的日期也分别设置。

- **今：**始终指当天，与日历当前翻到哪天无关。隔天可再次加入今天，已有的其他安排日期保留。
- **排：**点击日期立即保存并高亮，再点一次取消；可以翻月选择多天。点浮层外、关闭按钮或按 Esc 收起。
- **截止：**选择、修改或清空日期，显示完整年月日。任务行控件顺序为“截止 → 今 → 排”。

同一任务显示在各个安排日及截止日；日期重合时合并为一张卡片。**只有截止当天显示红底，其他安排日保持暖灰褐色。**

各日期共用同一条源任务和完成状态，任意一处勾选都会同步。没有安排日期、截止日期的任务，可在收集箱或项目任务树中查看。

## 使用日历

用 **Month／Week／Day** 切换月、周、日，左右箭头翻页，**Today** 回到今天。所选视图、日期和调整后的高度会保存。

| 日历操作         | 结果                   |
| ------------ | -------------------- |
| 拖动某一天的安排卡片   | 只移动该天安排，保留其他安排日及截止日期 |
| 拖动仅代表截止日期的卡片 | 修改任务截止日期             |
| 拖动安排与截止重合的卡片 | 移动该天安排，截止日期仍保留在原日    |
| 勾选任务         | 同步源任务、其他日期卡片和项目进度    |
| 眼睛按钮         | 显示或隐藏已完成任务           |
| 右键创建任务       | 写入收件箱，所选日期作为任务截止日期   |

已完成任务默认保留，以勾选、淡化样式显示。归档项目与模板中的任务不在首页日历中显示。

重复任务通过 Tasks 编辑器设置规则。完成后生成下一次任务，新任务需重新安排工作日期；历史安排保留在已完成的实例上。

## 删除、撤销与排序

收集项和项目任务右侧的“×”会删除该项、全部子任务及其缩进说明。通知中的“撤销”保留 **15 秒**；期间若同一笔记又有修改，旧撤销会停止，以保留新内容。

在首页或项目总览的任务区域，按 **Ctrl+Z** 撤销最近一次已保存操作，Mac 使用 **⌘Z**，提示会说明撤销了什么。连续按可逐步撤销，当前插件会话保留最近 **30 次**记录，重启或重新加载插件后清空。

- 支持添加、完成、删除和恢复任务，修改名称、截止及安排日期，同级排序、收集箱移入，以及项目改名、截止日期、完成／恢复和归档。移入项目会同时恢复收件箱与目标项目。
- 正在输入文字、选择日期或使用输入法时，快捷键保留给输入控件；要撤销已保存的首页操作，先退出输入或点到页面空白处。实时预览中的只读任务控件也支持；源码编辑保持 Obsidian 原有的撤销。
- 新建项目或领域后，从新的操作开始记录；快捷键不会删除刚创建的项目笔记或领域文件夹。重新打开项目的说明链接、展开／折叠和眼睛切换不计入撤销。
- 撤销前会核对笔记内容与位置，出现后续编辑、同步修改或同名文件占用时停止，以保留现有内容。当前仅提供撤销，未增加重做快捷键。

按住左侧“⋮⋮”拖动：放到目标行上半部排在前面，下半部排在后面。

项目排序保存为首页和项目总览的显示顺序。任务只能在同一父任务、同一章节内调整；拖动父任务会带上子任务，任务顺序也会写回项目笔记。

## 项目完成、恢复与归档

首页仅显示进行中的项目。[[00 GTD/00 工作区/00 功能页面/项目总览|项目总览]]可查看未归档的项目，包括已完成项目；[[00 GTD/00 工作区/00 功能页面/项目属性.base|项目属性]]可批量编辑领域、状态、完成标准和项目截止日期。

点项目状态后的“▾”打开操作菜单：

- **完成项目：**状态改为 `done`，从首页项目进度隐藏；各任务的勾选状态保持原样。
- **恢复进行中：**在项目总览中恢复为 `active`，重新显示在首页。
- **归档项目：**移入 `99 归档`，保留原领域子目录、任务、日期和记录，从首页项目进度与日历中排除。归档目标已存在同名文件时会停止，保留原项目。

项目完成与任务完成分别记录。**仅完成项目不会清除日历中的任务安排，归档后才从首页日历排除。**

恢复归档项目时，将笔记移回原领域的项目文件夹；已完成的项目再通过项目总览菜单恢复进行中。

## 目录与运行条件

```text
00 GTD/
├─ 首页.md
├─ 使用说明.md
└─ 00 工作区/
   ├─ 00 功能页面/  收件箱、项目属性、项目总览
   ├─ 01 项目/      按编号领域文件夹存放
   ├─ 02 领域/      领域笔记
   ├─ 04 模板/      项目模板
   ├─ 05 系统视图/  首页导航与项目进度脚本
   └─ 99 归档/
```

新领域的项目文件夹按现有最大编号顺延，新建项目加入所选领域。同一领域文件夹内的项目不能重名，领域名称也不能重复。

需要启用 **GTD 快捷操作、Dataview、Tasks、Tasks Calendar**，并开启 Dataview 的 JavaScript 查询。阅读模式和实时预览均可使用。

样式使用 `gtd-dashboard` CSS 片段，作用于 `00 GTD` 页面内容；侧边栏、标签栏及其他文件夹保持原主题。其他设备需同步笔记、配套插件、配置和 CSS 片段，并在目标设备启用。

## 常见情况

- **任务未出现在日历：**先用“今／排”安排日期，或设置任务截止日期，再翻到对应日期。只填写项目截止日期不会生成任务卡片。
- **点名称后没有展开项目：**名称用于改名，展开、折叠请点左侧箭头。
- **名称提示保存失败：**查看输入框下的原因。重名或名称格式问题可直接修正；源笔记已变化时，先复制草稿，再取消并重新点击名称编辑。
- **提示内容已变化：**等待视图刷新后重新选择目标。添加子任务时，重新点父任务“＋”可更新位置。
- **收集项从首页消失：**打开收件箱查看完成记录，首页只显示未完成事项。
- **项目从首页消失：**到项目总览检查完成状态；已归档项目在 `99 归档` 中。
- **看到代码块或控件未显示：**切换到阅读模式或实时预览，并检查上述插件与 JavaScript 查询是否启用。

未提交的行内草稿保留在当前会话中，页面重绘后可继续编辑；关闭或重启应用前请先保存。
