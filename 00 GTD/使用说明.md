# 使用说明

[← 返回工作台](首页.md) · [快捷键速查](#快捷键速查)

## 1. 先把待办记下来

![首页右侧的快速收集和移入，左侧的加项目和项目卡片](00%20工作区/06%20图解/01-home.png)

1. 在首页的**收集箱**点 **快速收集**，输入一件事，比如「整理会议记录」。按 **Enter** 或点 **收集**。可以连续记，记完点 **关闭**。
2. 整理时，点事项右侧的 **移入**，选择所属项目。父任务选 **无（创建顶层任务）**，它就会放在项目的第一层。选了父任务，就会放到它下面。
3. 再点 **移入** 确认。临时小事可以直接在收集箱勾选完成，误记的事项可以用行末的 **×** 删除。

## 2. 打开项目，把任务拆小

![项目页中的两个加号和正在输入的子任务](00%20工作区/06%20图解/02-tasks.png)

1. 在首页的**项目进度**里点 **+项目**，填项目名称、选所属领域，再点 **创建项目**。需要新的分类时，先点 **+领域**。
2. 点首页的项目卡片进入项目页。点**项目名旁的 ＋** 添加第一层任务，点**任务行右侧的 ＋** 添加子任务。比如在「准备一场分享」下面加「挑选三个案例」。
3. 输入后按 **Enter** 保存。光标留在输入框，可以继续添加同级任务。输入中点到别处会暂存草稿，再点同一个 **＋** 可以继续写。按 **Esc** 则关闭输入框并清掉本次草稿。

点击任务名或项目名可以改名，按 **Enter** 保存，按 **Esc** 取消。拖动左侧的点状手柄可以调整顺序，首页同一领域的项目左右拖，项目页同一层的任务上下拖。

## 3. 给任务安排日期

![任务行的截止、今、排按钮，以及已选中两天的日期面板](00%20工作区/06%20图解/03-schedule.png)

| 任务行按钮 | 怎么用 |
| --- | --- |
| **今** | 点一下加入今天，再点一下移出今天。 |
| **排** | 在弹出的日历里选一天或多天。点一下就保存，再点同一个日期就取消。 |
| **截止** | 选择最晚要完成的日期。整个项目的期限可以在项目页上方的 **截止日期** 修改。 |

图里的「制作演示稿」安排在 11 月 26 日和 27 日，截止设在 27 日。日历里两天都能看到它，只有 27 日的卡片是红底。

给父任务设置 **今** 或 **排** 时，未完成、未取消的各级子任务会加入所选日期。取消安排时，整条分支一起移出这一天。设置父任务的截止日期时，只补上子任务空着的截止日期。

## 4. 看日历，做完就勾选

![周日历里同一任务出现两天，只有截止当天显示红底](00%20工作区/06%20图解/04-calendar.png)

- 在项目页点 **← 工作台** 回首页。日历右上角用 **Month（月）**、**Week（周）**、**Day（日）** 切换视图。左边的箭头翻日期，**Today** 回到今天。
- 日历显示已经安排日期或设了截止日期的末级任务，也就是没有子任务的那一条。鼠标放到卡片上可以看它属于哪个项目和父任务。日视图还可以用 **路径** 或 **分组** 查看当天任务和下方的逾期任务。
- 在日历或项目页点任务前的方框就能完成。任务排了多天时，勾一次就会同步到其他日期和项目页。普通点击时，先完成全部子任务，再勾选父任务。需要整组一起完成时，可以用下表的 **Ctrl ＋ 左键**。
- 想专心做一件事时，点首页日历工具栏的 **专注**。从今天安排或今天截止的未完成末级任务里选一件，小字会显示它属于哪个项目和父任务。点 **30 分钟**、**60 分钟**，或输入自定义分钟数后点 **开始**。按钮会显示剩余时间，切页、刷新后会接着计时。再点按钮可提前结束，到点会提醒一次。任务做完后，由你手动勾选。
- 点项目页或日历右上角的**眼睛**，切换已完成任务的显示。日期格出现 **更多** 时，点它查看当天的任务。整个项目结束后，在项目页点**状态旁的小箭头**，选择完成或归档。

## 快捷键速查

在首页按 **Tab**，直到选中要打开的项目卡片，按 **Enter** 或**空格**打开。进项目页后，先点项目行或任务行的**空白处**选中该行，再按下表操作。

| 按键 | 在哪里用 | 会做什么 |
| --- | --- | --- |
| **↑ / ↓** | 项目页 | 移到上一行或下一行。 |
| **← / →** | 项目页 | 按 **←** 折叠或回到上级，按 **→** 展开或进入第一个子任务。 |
| **Home / End** | 项目页 | 跳到第一行或最后一行可见内容。 |
| **Enter** | 父任务行 | 展开或折叠子任务。 |
| **空格** | 项目行或任务行 | 开始改名。 |
| **=** 或 **+** | 项目行或任务行 | 给项目加第一层任务，或给当前任务加子任务。直接按等号键即可。 |
| **T** | 任务行 | 加入今天，再按一次移出今天。相当于点 **今**。 |
| **Delete** | 任务行 | 删除这条任务及其子任务。 |
| **Enter / Esc** | 输入框 | Enter 保存改名或添加任务，Esc 取消当前输入。 |
| **Ctrl ＋ 左键** | 项目页的任务复选框 | 同时完成这一项和它的各级子任务。 |
| **Ctrl+Z**（Mac **⌘Z**） | 首页或项目页 | 退出输入框后，撤销最近一次已保存的操作，例如误删、误勾选或排错日期。 |

在输入框里，方向键、空格和 Delete 照常用来编辑文字，**Ctrl+Z** 撤销打字。
