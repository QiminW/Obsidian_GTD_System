# 使用说明

[[00 GTD/首页|← 返回工作台]]

## 1. 先把待办记下来

在首页点 **快速收集**，写下一件事。准备归类时，点该项右边的 **移入**，选一个项目。

![首页右侧的快速收集和移入，左侧的加项目和项目卡片](00%20工作区/06%20图解/01-home.png)

## 2. 打开项目，把任务拆小

点首页左侧的 **+项目**，填名称、选领域。点首页的项目卡片打开任务页。项目名旁的 **＋** 添加第一层任务，任务行末的 **＋** 添加子任务。输入后按 **Enter** 保存。

![项目页中的两个加号和正在输入的子任务](00%20工作区/06%20图解/02-tasks.png)

## 3. 给任务安排日期

**今** 把任务加入今天，**排** 可以选多天，**截止** 填最晚完成的日期。

![任务行的截止、今、排按钮，以及已选中两天的日期面板](00%20工作区/06%20图解/03-schedule.png)

## 4. 看日历，做完就勾选

回到首页，日历右上角用 **Month（月）**、**Week（周）**、**Day（日）** 切换视图。**红底**表示当天到期，点任务前的小方框标记完成。

![周日历里同一任务出现两天，只有截止当天显示红底](00%20工作区/06%20图解/04-calendar.png)
